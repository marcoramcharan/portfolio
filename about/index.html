👤Introduction

I'm Marco Ramcharan, a self-taught software developer from Durban, South Africa. My path into software began in carpentry, where precision, practical problem-solving, and building things that last mattered every day.

I later moved into software development, contributing to a live production Consent Management Platform at Decidio. I work across application development, backend systems, APIs, and infrastructure — with a focus on reliable, real-world software.

I'm currently open to full-time software engineering roles.

Featured · Professional Experience

Truendo — Consent Management Platform

Decidio GMBH · Production Software · Live Product

At Decidio GMBH, I contributed to Truendo, a live consent management platform used by enterprise clients. My work spanned backend APIs, client-facing SDKs, and full-stack features — alongside infrastructure work including Kubernetes deployments, CI/CD pipelines, CDN migrations, and database optimisation.

Day-to-day, I worked in TypeScript, React, and Go within a production environment — deploying to containerised infrastructure and contributing to the reliability and performance of a real, running product.
